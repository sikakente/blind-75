# Blind 75

Python solutions to the [Blind 75](https://leetcode.com/discuss/general-discussion/460599/blind-75-leetcode-questions) curated list of LeetCode problems — a popular set of coding interview questions covering essential data structures and algorithms.

## Structure

Solutions are organized by category, each in its own `.py` file containing a `Solution` class. Tests live in the `tests/` directory mirroring the same structure.

```
blind75/
├── arrays/
├── strings/
├── trees/
├── graph/
├── dynamic_programming/
├── linked_lists/
├── recursion/
├── stacks/
├── searching/
├── sliding_window/
├── hash_map/
└── tests/
```

## Running Tests

```bash
# Install dependencies
uv sync

# Run all tests
uv run pytest

# Run a specific test file
uv run pytest tests/arrays/test_two_sum.py -vv
```

## Requirements

- Python 3.9+
- [uv](https://docs.astral.sh/uv/)
